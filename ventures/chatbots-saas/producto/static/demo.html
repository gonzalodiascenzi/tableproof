Probá el chatbot

Esta es la web de un negocio de ejemplo, Vivero Ejemplo. El negocio es ficticio: sus precios y horarios son inventados para la prueba.

Tocá ¿Consultas? abajo a la derecha y preguntale lo que le preguntaría un cliente.

Ideas para probar

  • ¿Qué horario tienen los sábados?
  • ¿Hacen envíos? ¿Cuánto salen?
  • ¿Qué planta me recomiendan para un balcón con poco sol?
  • ¿Venden muebles de jardín? (no está cargado: debería decir que no tiene el dato)

Es un asistente automático y puede equivocarse. No escribas datos personales. La demo tiene un tope diario de consultas.
